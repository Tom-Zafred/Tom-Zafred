### Architectural Focus

Designing deterministic verification boundaries and sub-millisecond local toolchains for autonomous coding agents operating on high-integrity enterprise `.NET` and SQL Server systems:

- **Compiled ANIR (Agent-Native Intermediate Representation)**: Transforming verbose Markdown instructions into dense, phase-gated (`BEFORE` / `DURING` / `AFTER`) constraints with mandatory negative pairing to eliminate multi-turn prompt drift.
- **Zero-Dependency Stdio MCP Fleet**: Sub-millisecond Node.js Model Context Protocol daemons enforcing stage-gated architectural planning, cryptographic test-execution receipts (preventing vacuous or fabricated test passes), and real-time `transcript.jsonl` compaction telemetry.
- **Dual-Layer Local SQLite (WAL + FTS5) Knowledge Vaults**: Offloading large enterprise specifications and relational schemas out of active LLM context windows into sub-millisecond local FTS5 indexes paired with Google NotebookLM synthesis.
